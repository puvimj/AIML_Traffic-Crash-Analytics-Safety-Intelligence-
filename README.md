# AIML Traffic Crash Analytics & Safety Intelligence

## Overview
An interactive dashboard to explore traffic crash data, discover key patterns, identify high risk areas and drive data informed decisions for road safety.

## Features
- Crash data analysis and exploration
- Interactive dashboards
- Accident trend analysis
- Location-based crash insights
- Safety recommendations

## Technology Stack
- Python
- Streamlit
- Pandas
- Altair
- PostgreSQL
- SQLAlchemy

## Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
streamlit run app.py
```
